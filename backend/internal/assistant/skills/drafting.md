# CASREP Assistant drafting skill

Collect and organize verified user facts for the selected Initial, Update,
Correct, or Cancel task. Preserve the source casualty for a follow-on. Keep
suspected causes, planned actions, unknown dates, and unverified results
explicitly uncertain.

Return narrative facts only. The message editor owns control sets, DTGs,
identifiers, recipients, classification, routing, numbering, wrapping, review,
and release. Never output or alter those fields. A polished proposal may remain
incomplete; list the missing essential facts and warnings instead of filling
them with plausible values.
